# 小学练习题库 · 1-6 年级

给小学生用的练习题库网页：家长选年级，孩子点开就做题，一套 20 道，自动判分、自动收错题。

无需注册、无广告、无内购，不用安装 App，**纯静态页面**，打开链接即可使用，断网也能做。
所有成绩与错题只保存在本机浏览器，不上传任何服务器。

## 在线使用

部署到 GitHub Pages 后：`https://tab1213.github.io/xiaoxue-tiku/`

也可以直接用 `single-file.html`：单文件、内联题库与图标，双击即可离线运行，方便拷到平板或 U 盘。

## 功能

- **1~6 年级**：家长在「家长」面板（默认密码 `1234`，建议修改）里选择年级，只出该年级的题
- **语文 / 数学 / 英语**：三年级起含英语，共 **576 道题**（选择 320 / 判断 128 / 填空 128）
- **三种题型**：四选一、判断题（对 / 错）、填空题（不区分大小写、空格可省略，`1/5` 与 `0.2` 均可）
- **每套 20 题**：默认按 6:2:2 混排，也可锁定只练某一种题型
- **自动判分**：交卷后给出得分、对错题数、用时，每道错题附正确答案与解析
- **错题驱动**：错题本记录错误次数，错得多的优先重练；同一题**连对 2 次**才算掌握，蒙对一次不算
- **薄弱点**：首页按科目统计错题与掌握进度，点一下直接专练该科
- **多端自适应**：手机、平板、电脑、电视大屏均可；遥控器可用方向键操作，数字类填空题会弹出屏幕键盘
- **可添加到主屏幕**：内置 manifest 与 Service Worker，iPad / Android 可像 App 一样打开并离线使用

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 全部界面与逻辑（首页 / 答题 / 成绩 / 错题本 / 家长面板） |
| `bank.js` | 题库，`BANK[年级][科目] = [题目]` |
| `sw.js` | 离线缓存 |
| `manifest.webmanifest` | PWA 清单 |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | 图标 |
| `single-file.html` | 单文件离线版（题库与图标已内联） |

题库题目结构：

```js
// 选择题
{ t: 'choice', q: '题干', o: ['A', 'B', 'C', 'D'], a: 2, e: '解析' }
// 判断题
{ t: 'tf', q: '题干', a: 1, e: '解析' }          // 1 = 对，0 = 错
// 填空题
{ t: 'fill', q: '题干', a: ['答案', '另一种写法'], e: '解析' }
```

## 本地运行

纯静态，起个静态服务器即可（直接双击 `index.html` 也能用，但 Service Worker 与「添加到主屏幕」需要 HTTP/HTTPS 环境）：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

## 部署到 GitHub Pages

1. 把本目录全部文件上传到仓库根目录（`index.html` 必须在根目录）
2. 仓库 **Settings → Pages → Source** 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`，保存
3. 一两分钟后访问 `https://<用户名>.github.io/<仓库名>/`

`.nojekyll` 用于跳过 Jekyll 处理，保证静态文件原样发布。
