综合卷不是随手拼的：小学按 6:2:2、初中按 12:4:4 的比例混排三种题型；只练单科时按该科题库权重抽题，保证每套都能覆盖不同知识点。

## 为什么孩子愿意做

- **一屏一题**，没有列表、没有加载动画，点「开始测试」立刻出题
- **点一下就判**：选择题点选项，判断题点「对 / 错」，填空题带屏幕键盘，电视遥控器也能用方向键操作
- **交卷即出分**：得分、对错题数、用时，每道错题附正确答案和一句解析
- **错题驱动**：错题本记录每题错误次数，错得最多的优先重练；同一题**连对 2 次**才算掌握（可调），蒙对一次不算
- **薄弱点直击**：首页按科目统计错题，点一下就专练最弱的那一科
- **家长不催不吼**：孩子看到分数和进度，家长看到薄弱科目，不用在一旁盯着

## 数据与隐私

所有成绩、错题、设置**只存在本机浏览器**（`localStorage`），不上传任何服务器，不采集任何信息，没有第三方统计脚本。换设备或清缓存会丢记录，这是刻意的设计。

家长面板默认密码 `1234`（可在面板内修改），只用于防止孩子误改设置，不是账号体系。

题库题目结构：

```js
// 选择题
{ t: 'choice', q: '题干', o: ['A', 'B', 'C', 'D'], a: 2, e: '解析' }
// 判断题
{ t: 'tf', q: '题干', a: 1, e: '解析' }          // 1 = 对，0 = 错
// 填空题
{ t: 'fill', q: '题干', a: ['答案', '另一种写法'], e: '解析' }
```

填空题判分比较宽容：忽略大小写与多余空格，`1/5` 与 `0.2`、`3.14` 与 `3.140` 都算对，一题也可写多个可接受答案。

## 本地运行

纯静态，起个静态服务器即可（双击 `index.html` 也能做题，但 Service Worker 与「添加到主屏幕」需要 HTTP/HTTPS）：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

## 部署到 GitHub Pages

1. 把本目录全部文件上传到仓库根目录（`index.html` 必须在根目录）
2. 仓库 **Settings → Pages → Source** 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`
3. 一两分钟后访问 `https://<用户名>.github.io/<仓库名>/`

`.nojekyll` 用于跳过 Jekyll 处理，保证静态文件原样发布。
